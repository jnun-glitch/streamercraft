# OBS-Integration

Es gibt noch keinen OBS-Gateway-Dienst und keine OBS-Szenensteuerung. Die spätere Browser-Overlay-Integration muss lokal an Loopback gebunden werden, einen zufälligen Zugriffstoken verwenden, externe Verbindungen ablehnen und standardmäßig deaktiviert bleiben. Ohne OBS muss die Mod normal funktionieren.
